# What is a Large Language Model (LLM)? 
Start with this [brief explanation from 3Blue1Brown](https://www.youtube.com/watch?v=LPZh9BOjkQs). For more context, see the [larger 3Blue1Brown playlist on Neural Networks](https://www.youtube.com/playlist?list=PLZHQObOWTQDNU6R1_67000Dx_ZCJB-3pi). 
## LLM basics for CSSE 220
*This description is borrowed from course materials of Sam Lau at UCSD.*

- We can think of an LLM as a statistical language model, trained on a massive amount of data, that can be used to generate text, code, and other content. 
- LLMs can be trained to recognize:
	- Patterns between words, phrases, and concepts
	- Coding styles, syntax, paradigms, and programming practices
- LLMs trained on code data can be used for code generation, debugging, code analysis, and problem-solving across many programming languages.
	- For example, developers can use LLMs to quickly create code snippets, functions, or entire programs by describing the desired functionality in natural language. 
	- The LLM then processes the input prompt and uses its training data to understand the context and requirements, and generates code that the developer can review, test, and integrate into their project.
